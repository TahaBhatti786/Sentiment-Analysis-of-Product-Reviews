# Project Summary

## Overview

This project focuses on sentiment analysis of Amazon Alexa product reviews using Natural Language Processing (NLP) and machine learning techniques.

## Dataset

- Amazon Alexa Reviews Dataset
- File Format: TSV
- Target Classes:
  - Positive
  - Negative

## Methodology

1. Data Loading
2. Data Cleaning
3. Text Preprocessing
4. Exploratory Data Analysis
5. Bag of Words
6. TF-IDF Vectorization
7. Logistic Regression
8. Multinomial Naive Bayes
9. Model Evaluation
10. Model Comparison

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- ROC Curve

## Conclusion

Logistic Regression provided the best performance on the Amazon Alexa Reviews dataset and was selected as the final model.

The project demonstrates the complete workflow of a classical NLP text classification problem.
